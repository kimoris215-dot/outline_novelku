# Novel Consult

Novel Consult adalah aplikasi web pribadi untuk membantu proses menulis, mengembangkan, dan mengelola novel.

## ✨ Fitur

- 🏠 Dashboard / Beranda
- 📖 Manajemen novel
- 📝 Manajemen chapter
- 🗺️ Story Planner
- 👤 Database karakter
- 💬 Konsultasi novel
- 💡 Idea Vault
- 📊 Progress menulis
- ⚙️ Pengaturan
- 🎨 Maskot dan tampilan visual
- 📈 Statistik dan progress penulisan

## 🛠️ Teknologi

Project ini dibuat menggunakan:

- React
- Vite
- JavaScript / JSX
- CSS
- Lucide React
- Recharts
